# 🤖 Bot de Correio Anônimo no Telegram

Este projeto é um bot do Telegram que permite o envio de mensagens anônimas para um grupo, com sistema de aprovação por administradores. Ideal para criar um canal seguro e moderado de comunicação entre membros.

---

## ✨ Funcionalidades

- Envio de mensagens anônimas via chat privado
- Aprovação ou recusa por administradores antes da publicação
- Interface com botões interativos para moderação
- Controle de inicialização e encerramento do bot via comandos `/start` e `/end`
- Mensagens personalizadas para usuários dependendo do estado do bot
